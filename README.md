# Joc Memory

Enllaç: https://bas.udg.edu/~u6103664/P1_web/

## Introducció
Projecte d'un joc Memory fet amb HTML, CSS i JavaScript.

## Disseny
- Menú principal
- Joc en canvas
- Opcions per Mode 1 i Mode 2
- Top 10 de puntuacions

## Implementació rellevant
- Mode 1 estàndard i Mode 2 progressiu.
- Cartes en SVG i render dins del canvas.
- Guardar/carregar partida en localStorage (sense PHP).
- Puntuacions en sessionStorage.

## Problemes trobats
- Integrar completament el canvas al flux principal.
- Fer el layout de cartes adaptable al contenidor.
- Ajustar la victòria final del mode progressiu.

## Conclusió
S'ha obtingut un joc funcional, simple i extensible, amb dos modes i persistència local.
